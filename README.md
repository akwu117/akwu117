## Featured project: The MLS Metric

[The MLS Metric](https://github.com/akwu117/themlsmetric) is my soccer analytics project. It uses a custom scoring system to compare tracked Major League Soccer players across weekly snapshots.

In the [April 7–14, 2025 SQL case study](https://github.com/akwu117/themlsmetric/tree/main/case-studies/25APR07-14), I:

- Compare player values across two snapshots using a self-join.
- Investigate changes in goals, assists, shots, and key passes.
- Check goal rewards against the project's $150,000-per-goal rule.
- Trace a discrepancy back to a manually entered spreadsheet value and correct the source formula.
- Document the findings, pending database updates, and data-quality issues that need further review.
